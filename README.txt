個人資遣試算器 — Android 專案原始碼

相容性：minSdk 31（Android 12 / One UI 4.1 起），面向 Android 12 及更新版本。
本專案不是已編譯 APK。要產生 APK，需在 Android Studio 開啟資料夾並建置。

桌面小工具功能：
- 顯示在職天數、假設今日資遣的估算總額、資遣費、預告工資及週會加班費
- 週會以 2026-11-03 的 15 次為基準，按日曆週增加；桌面 − / + 可調整偏差
- 調整值保存在本機 SharedPreferences

重要試算假設：
- 月薪 39,300 元暫作平均工資估算；資遣費按 elapsedDays/365 比例
- 預告天數以 90/365/3*365 天作簡化判斷
- 周會按平日延長工時前 2 小時 1.34 倍估算
- 小工具系統更新頻率由 Android 管理，通常不保證精確到某一分鐘
- 法定年資、平均工資、週會是否屬加班及實際結算仍須核實

注意：這是個人用途的估算工具，非法律或薪資結算結果。
